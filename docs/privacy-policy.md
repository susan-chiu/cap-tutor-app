## 一、我們收集哪些資料

| 資料 | 用途 | 是否必要 |

| Email、密碼（加密儲存） | 建立帳號、登入 | 必要 |

### 關於廣告

免費版只有在你主動按下「看廣告，多一次小老師」時才播放廣告，完整版沒有廣告。
我們要求廣告商只提供**非個人化**、**普遍級**的廣告，並告知廣告商使用者可能未滿法定年齡，
不會用你的學習資料投放廣告。

## 二、未成年人

本 App 的主要使用者為國中生（約 12～15 歲）。未滿 18 歲的使用者應在父母或監護人同意下註冊、使用與購買。
家長可以透過孩子提供的邀請碼綁定帳號，查看學習摘要（練習天數、答對率、較弱單元、錯誤類型統計），
**看不到**對話內容。學生可以在「我的」頁面查看哪些家長已綁定、隨時解除綁定，或更換新的邀請碼。

## 二之一、AI 錯題小老師

- 小老師的講解由 AI 產生，可能出錯；看到錯誤或不恰當的內容，請按畫面右上角「回報」，我們會人工檢查。
- 第一次使用前，App 會說明並徵求你的同意。同意後，這一題的題目、你的作答與你輸入的文字會傳送到
  Anthropic, PBC（美國）處理以產生講解；不會傳送 Email、真實姓名或學校。
- 依 Anthropic 的商業服務條款，透過 API 傳送的資料預設不會被用來訓練 AI 模型。[上架前請到 Anthropic 官網確認最新的資料保存期間並填入]
- 請不要在對話中輸入姓名、電話、地址等個人資料。
- 系統會偵測情緒低落或危險的字詞，暫停講解並提供求助專線。

## 三、資料處理者

- 資料儲存於 Supabase（[所選區域，例如日本東京]）的伺服器。
- 錯題小老師的講解由 Anthropic 的 Claude API 產生；我們只傳送題目、學生作答與對話內容，不傳送 Email 或真實姓名。
- 付款由 Apple App Store 或 Google Play 處理，我們不會取得你的信用卡資料；訂閱狀態透過 RevenueCat 管理。
- 廣告由 Google AdMob 提供。
- 當機紀錄由 Sentry（美國）處理，不包含 Email；我們已關閉 IP 位址收集。
- 以上服務可能位於臺灣以外的地區（日本、美國），屬於個人資料的國際傳輸。
- 系統信件（註冊確認、重設密碼）由 [寄信服務，例如 Resend] 寄送。

## 四、保存與刪除

- 帳號資料在你使用期間保存。
- 成績證明照片於審核完成後刪除；申請紀錄（學校、年級、名次、審核結果）保存到帳號刪除為止。
- 小老師對話紀錄保存到帳號刪除為止，只用於提供服務與處理回報。
- 你可以隨時在 App「我的 → 刪除帳號」永久刪除帳號與所有資料。

## 五、資料外洩

若發生個人資料外洩，我們會依法儘速通知受影響的使用者與主管機關，並說明處理方式。
